## 2. 이번 세션 타임라인 (시간순 요약)

1. **화장품 전이학습용 mixture 데이터 탐색** — COSMOS Database 조사:
   - 사용자가 보낸 `cosmos-dataset.readthedocs.io`는 완전히 다른 프로젝트(이미지-뉴스캡션 진위검증용, Aneja et al.) — 무관함
   - 진짜 COSMOS(cosmostox.org, EU SEURAT-1 클러스터, 2011~2015, repeated dose toxicity 전문)는 로그인까지 해서 Database Search → Toxicology Study Filter를 직접 확인한 결과 **"Irritation" 카테고리 자체가 없음**(Acute Toxicity 등 전부 1~12건 수준 희소 데이터) → **skin/eye 자극성 용도로는 폐기 확정**
   - File Downloads는 전부 TTC(발암성/전신독성 역치) 계열이라 무관

2. **화장품+피부/안자극성 논문 전수조사** — 6개 분야(SCCS/식약처/실제상업제품/계면활성제/방부제·향료/UV차단제)로 쪼개 Agent 병렬 디스패치. **API 세션 한도(6:50pm 리셋)에 대부분 걸려 실패.** 확보된 것:
   - **Phenoxyethanol** (CAS 122-99-6): skin EPA IV/이진0, eye EPA II/이진1 — SCCS/1575/16(2016) 원문 직접확인, **high confidence**, `cosmetic_validation\cir_ingredients.csv`에 **아직 미반영**
   - 향료 알레르겐(d-Limonene/Citral/Linalool/Cinnamyl Alcohol/Geraniol/Eugenol/Coumarin) 배치는 전부 검색엔진 요약 기반이라 품질 낮음 → **보류**. Geraniol만 추후 ECHA dossier 원문 재검증 가치 있음(PDII 3.8/2.2/3.31 여러 연구서 일관된 수치)
   - 나머지(SCCS 메인, 식약처, 실제상업제품, 계면활성제, UV차단제 그룹A/B/C/완제품) **전부 미완료 — 재시도 필요**

3. **사람1의 production 실험 결과 PDF 2건 수신·분석**:
   - `EPA_라벨조합_실험결과_보고서.pdf`: skin 662행·eye 673행, A(EPA1·2=양성)/B(EPA1·2·3=양성) × 6모델(CatBoost 제외). **최고 조합: Eye A+LR(MCC 0.380)**, skin은 B+Extra Trees가 최고(MCC 0.293). 이 보고서는 **결측치 0-대체**(dropna 아님)로 전체 662/673행을 다 씀 — 기존 하네스(skin 541건/eye 604건, dropna)와 전처리 방식이 다름, 사람1에게 의도된 변경인지 확인 필요(미확인 상태로 남음)
   - `EPA_GHS_라벨조합_실험결과_보고서.pdf`: eye만(skin은 GHS mixture 자료 없어서 미실행 — 이전 세션에서 확인한 것과 일치). GHS 55행을 보조라벨로 증강해도 **효과 없음**(MCC 평균 -0.024). 핵심 원인: **배합비(성분별 질량비) 확인된 행이 0개** — 전체구조(whole SMILES)로만 인코딩해서 도움이 안 됨. "GHS 데이터가 무용하다"가 아니라 "배합비 없는 GHS는 안 도움된다"로 해석할 것.

4. **skin 모델 성능 개선 작업 시작** — "최악 성분 하나가 자극성을 지배한다"는 가설 검증:
   - 기존 `skin irritation\notebooks\skin_aggregation_comparison.ipynb` 발견: 8개 공통 descriptor만으로 wmean/top/max/min 비교, 원본 544건, A라벨, RF only → **min이 wmean보다 뚜렷이 좋음**(PR-AUC 0.297 vs 0.131)
   - 이를 **전체 feature(2,273차원=공통8+desc217+fp2048) + B라벨 추가 + Extra Trees**로 확장한 새 노트북 작성: `skin irritation\notebooks\skin_aggregation_comparison_full_features.ipynb`
   - **스코프 제한**: 집계방식 비교는 성분구성비 원자료(`skin_filtered.csv`)가 있는 **원본 544개 제형에만** 적용 가능(증강 118건은 집계방식 재계산용 원자료가 기본적으로는 없다고 생각했으나, 확인 결과 **`skin_보강후보_통합.xlsx`/`v4_신규.xlsx`에 `성분함량` 시트가 실제로 존재**해서 완전히 불가능한 건 아님 — 다만 함량이 범위값(예:"35-40")이고 `변환정책=preserve_raw_no_imputation_no_renormalization`이라 범위값 처리방식부터 새로 정해야 해서 품이 많이 듦. **이 작업은 아직 안 함.**)
   - **결과 (541건, 3건 feature NaN 제외)**:

     | label | 모델 | 1위 방식 | MCC | wmean MCC | 차이 |
     |---|---|---|---|---|---|
     | A(n_pos=30) | ExtraTrees | min | 0.213 | 0.170 | +0.043 |
     | A(n_pos=30) | RandomForest | **min** | **0.322** | 0.251 | **+0.071** |
     | B(n_pos=99) | **Extra Trees**(팀 목표 조합) | **top** | **0.260** | 0.221 | **+0.040**(변동폭보다 큼) |
     | B(n_pos=99) | RandomForest | top | 0.249 | 0.199 | +0.050 |

   - **중요 발견**: label A에서는 `min`이 최고인데 label B에서는 `min`이 오히려 최하위(top이 최고) — "최악성분 지배" 가설은 라벨 정의(엄격 A vs 완화 B)에 따라 다르게 작동함
   - wmean 재계산값이 production `skin_vectorized.csv`와 2,273컬럼 전부 1e-6 이내 일치 확인(파이프라인 정합성 검증 완료)
   - 저장된 그림: `skin irritation\skin_aggregation_full_features_comparison.png`, `skin irritation\skin_aggregation_full_features_B_extratrees_mcc.png`

5. **concat(두 집계방식 섞기) 실험 추가** — 같은 노트북에 7~10단계 셀 추가(wmean+top/wmean+min/wmean+max/top+min/top+max/min+max 6개 조합 × A/B × ExtraTrees/RF = 24개 추가 조합, 4,546차원).

  cd "C:\Users\UserK\학술제\skin irritation\notebooks"
