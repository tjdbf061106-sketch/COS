# 교수님께 여쭤볼 내용 — 클래스 불균형 처리 + Multi-task 가중치(α/β) 설계

## 1. 클래스 불균형 처리

**데이터 현황 (skin)**
- 비독성 512건 / 독성 29건 (약 1:17.8)

**현재 구현한 방식**
`CrossEntropyLoss`에 클래스별 가중치를 줘서, 소수 클래스(독성)를 틀렸을 때 손실(loss)을 더 크게 매기는 **class-weighted cross entropy**를 사용했습니다. 가중치는 `전체샘플수 / (클래스수 × 해당클래스샘플수)`로 계산해서, 클래스 비율의 역수만큼 벌점을 줍니다(독성 쪽 가중치가 비독성보다 약 17.8배 큼).

1:1 언더샘플링(다수 클래스를 소수 클래스 수만큼 줄이는 방법)도 코드엔 옵션으로 넣어뒀지만, skin은 독성이 29건뿐이라 1:1로 맞추면 전체 데이터의 상당수(비독성 483건)를 버리게 되어 **기본값으로는 쓰지 않기로 했습니다.**

**여쭤보고 싶은 점**
- skin처럼 비율이 1:17.8까지 극단적인 경우에도 class-weighted CE 하나로 충분한지, 아니면 focal loss 같은 다른 기법을 같이 고려해야 하는지
- 독성 샘플이 29건뿐이라는 절대적인 수 자체가 신경망 학습에 너무 적은 건 아닌지(가중치를 아무리 잘 줘도 "본 적 있는 패턴"이 너무 적어서 일반화가 안 될 위험)

## 2. Multi-task 손실 가중치(α, β) 설계

**배경**: 저희 모델은 skin/eye를 하나의 Multi-task 신경망으로 묶어서 학습하고, 최종 손실은 `total_loss = α·skin_loss + β·eye_loss`로 계산합니다(지도교수님 피드백대로 반영).

**현재 구현한 방식**
α/β를 사람이 고정된 숫자로 미리 정하지 않고, **학습 가능한 파라미터로 만들어서 역전파 과정에서 모델이 스스로 값을 조정**하도록 했습니다. 구체적으로는 `α = sigmoid(raw_alpha)`, `β = 1 - α`로 두어 항상 0~1 사이, 합이 1이 되도록 제약했고, 초기값은 α=β=0.5(동등 비중)에서 시작합니다.

**여쭤보고 싶은 점**
- 이렇게 α/β를 학습 가능한 파라미터로 자동 최적화하는 방식이 타당한지, 아니면 고정값(예: 데이터 양이나 난이도에 비례)으로 미리 정하거나 그리드서치처럼 실험적으로 바깥에서 탐색하는 게 더 적절한지
- 학습 가능한 α/β의 경우, loss를 줄이는 가장 쉬운 방법이 "어려운 task(예: skin처럼 데이터가 적고 불균형 심한 쪽)의 가중치를 낮춰버리는 것"이 되어서, 모델이 그 task를 제대로 학습 안 하고 회피하는 쪽으로 수렴할 위험은 없는지(이런 경우 불확실성 기반 가중치 같은 대안 기법을 써야 하는지)
