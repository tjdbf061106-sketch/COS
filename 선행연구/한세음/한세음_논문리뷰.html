선행연구 리뷰 · 화장품 피부·안 자극성 예측 모델 개발 과제

논문 리뷰 — Kang, Kim & Lim (2023), Toxicological Research 39:295–305

Machine-learning based prediction models for assessing skin irritation and corrosion potential of liquid chemicals using physicochemical properties by XGBoost DOI: 10.1007/s43188-022-00168-8 · 이화여대 약학대학 (교신: Myeong Gyu Kim, Kyung-Min Lim)

왜 이 논문이 우리 과제와 직결되는가 이 연구는 한국화장품산업연구원(KCII) 화장품 안전성 평가 사업 + 환경부 KEITI 자금으로 수행됐다. 즉 우리 과제(①~⑤)와 동일한 정책적 목표를 가진 선행연구이고, 저자 그룹(임경민)은 ChemSkin DB의 원저자이기도 하다. 우리 연구의 직접적 baseline이자 벤치마크 상대로 잡아야 한다.

1. 한 줄 요약

구조로부터 계산한 물리화학적 descriptor 22개만으로, 액상 화학물질 545종의 UN GHS 피부 자극/부식 등급을 XGBoost로 분류했고, 정확도가 in vitro RhE 시험(OECD TG 431/439)과 동등한 수준(0.73~0.82) 에 도달했다. 기존 QSAR 상용 툴(Derek Nexus 0.51, Case Ultra 0.59)을 크게 상회한다.

2. 연구 설계 상세

2.1 데이터 — 우리와 출처가 다름

항목 내용
출처 1 ChemSkin DB (Han et al., Toxics 2021) — 100종, 최근 20년 문헌에서 in vivo 품질 검증
출처 2 eChemPortal GHS search — 748종 추가, 중복 없음
신뢰도 필터 ECHA reliability score로 in vivo 결과 신뢰도 심사
제외 기준 ① 혼합물 제외 ② 고체·기체 제외 ③ 물성값 결측 제외 ④ 상충 데이터 제외
최종 n 545종 (액상 순물질만) → 학습 436 / 테스트 109 (80:20)
라벨 Cat 1(부식) / Cat 2(자극) / Cat 3(경미) / NC — Cat 3은 OECD TG 431 기준에 따라 NC로 병합

[핵심 차이점]: 이 논문은 NTP ICE를 쓰지 않았다. eChemPortal(ECHA/REACH 기반)을 썼다. 우리는 ①단계에서 ICE를 쓰므로, ICE ∩ eChemPortal ∩ ChemSkin DB의 중복을 CASRN/DTXSID 기준으로 반드시 dedupe해야 한다. 안 하면 우리 test set이 이 논문 train set과 겹쳐서 성능이 부풀려진다.

2.2 Feature: 34개 → 22개

ChemTunes·ToxGPS에서 34개 descriptor 수집 → Pearson |r| ≥ 0.9 인 쌍에서 하나씩 제거 (다중공선성 제거) → 22개 확정.

선택된 22개: HAccO, HAccN, HDon, HDonO, HDonN, Ro5Viol, Stereo, Complex, ComplexRing, TPSA, Dipole, Polariz, LogS, Aspheric, Eccentric, InertiaX, InertiaY, Rgyr, HoF(AM1), HOMO(AM1), LUMO(AM1), HOMO-LUMO gap(AM1)

성격별로 보면 — 수소결합 (5) · 극성/용해도 (TPSA, Dipole, Polariz, LogS) · 3D 형상 (Aspheric, Eccentric, Inertia, Rgyr) · 양자화학 (AM1 준경험적 HOMO/LUMO/gap/생성열). Fingerprint를 전혀 쓰지 않았다는 점이 중요하다.

2.3 모델링

  • 알고리즘 7종 비교: LR, NB, KNN, SVM, RF, XGB, NN
  • 문제 정의를 3가지로 분해:
    • ternary: Cat 1 vs Cat 2 vs 비자극(NC/Cat 3)
    • binary A: 비자극 vs 자극(Cat 1+2) — TG 439 대응
    • binary B: Cat 1 vs 나머지 — TG 431 대응
  • Grid search + 10-fold CV, "민감도·특이도가 모두 높은" 조합 선택
  • 학습/테스트셋 feature 분포 동질성을 Mann–Whitney로 검정 (분할 타당성 확인)
  • 해석: SHAP summary plot + dependence plot
  • 환경: Google Colab, 전처리는 R

3.2 SHAP — 어떤 물성이 자극성을 결정하는가

분류 문제 상위 기여 descriptor
자극 vs 비자극 HOMO(AM1) > HAccN > LUMO(AM1) > HOMO-LUMO gap
Cat 1 vs 기타 HAccN > HOMO(AM1) > TPSA > LUMO(AM1)

방향성(dependence plot):

  • HOMO ≤ −11 eV → 자극성 / −10 근처 또는 ≥ −9 → 비자극. (단 −11~−9 구간은 혼재)
  • HAccN = 0 → 비자극, ≥ 1 → 자극 (질소 수용체 존재가 강한 신호)
  • LUMO < 0 → 자극 / 1~2 → 비자극
  • Cat 1은 추가로 TPSA 10~60 구간에 몰림

저자 해석: 독성은 반응성(reactivity) 과 강하게 연관되고, HOMO/LUMO는 전자 주개/받개 능력을, 질소 수용체와 분극률은 친전자/친핵 반응성을 대변한다는 것.

4. 한계 (저자 자인 + 리뷰어 관점 추가)

저자가 밝힌 한계

  1. 545종은 ML로는 여전히 적다.
  2. 학습 데이터 범위 밖 물질의 예측 성능은 보장 못 함.

5. 우리 연구(①~⑤)에 어떻게 쓸 것인가

① NTP ICE 데이터 확보

  • 이 논문의 큐레이션 프로토콜을 그대로 차용한다: (a) 혼합물 제외 (b) 물성 결측 제외 (c) 상충 라벨 제외 (d) 신뢰도 점수 필터(ECHA reliability ↔ ICE의 study quality flag). ICE도 동일하게 신뢰도 기반 필터링을 걸어야 "고품질 in vivo" 학습셋이 된다.
  • ChemSkin DB(100종)와 eChemPortal 데이터를 우리 셋에 추가 병합하면 545종 → 800종 이상으로 확장 가능. 단 CASRN/DTXSID로 중복 제거 + 라벨 충돌 시 신뢰도 높은 쪽 채택 규칙을 문서화.
  • ICE는 눈 자극성(BCOP, EIT, in vivo rabbit eye) 도 함께 제공하므로, 이 논문이 못 다룬 눈 자극성까지 커버하는 것이 우리의 1차 차별점.

② ICE 데이터 학습 (농약 제형 중심)

  • 문제 정의를 이 논문처럼 3분해해서 간다: ternary + binary(자극/비자극) + binary(Cat 1/기타). 그리고 ternary 예측을 2×2로 접은 결과와 전용 binary 결과를 둘 다 보고한다 (이 논문에서 전자가 더 좋았던 사례가 있음 — 0.780 vs 0.734).
  • 성능 목표선(acceptance bar)을 이 논문에서 그대로 가져온다: 자극/비자극 ACC ≥ 0.75, Se ≥ 0.80, Sp ≥ 0.70 (TG 439), Cat 1 ACC ≥ 0.79, Se ≥ 0.85, Sp ≥ 0.70 (TG 431). 이 논문은 Sp 0.42~0.52로 이 기준을 못 넘겼다 → 여기가 우리가 이길 수 있는 지점.
  • 농약 제형(formulation) 데이터는 이 논문이 명시적으로 배제한 "혼합물·희석액"이다. 즉 우리 ②단계는 이 논문의 적용범위 밖에서 시작한다. 따라서 혼합물 descriptor 처리 규칙을 먼저 정해야 한다 → 아래 ④ 참고.

③ 모델 구축

  • XGBoost를 1순위 후보로 두되, 7종 비교 구도를 그대로 재현해서 "우리 데이터에서도 XGB가 최적인가"를 보인다. 선행연구 재현은 심사에서 강력한 근거가 된다.
  • Feature 파이프라인: 34개 → Pearson |r|≥0.9 제거 → 22개 절차를 재현하되, HOMO/LUMO/gap/HoF(AM1) 계산 경로를 반드시 확보해야 한다. 이 4개가 SHAP 상위권이므로 빼면 성능이 떨어진다. RDKit만으로는 안 되고 MOPAC(AM1/PM7) 또는 GFN2-xTB가 필요. → 이 부분을 오픈소스로 대체하는 것 자체가 재현성 측면의 기여가 된다.
  • SHAP은 필수로 넣는다. 규제·심사 맥락에서 "왜 그렇게 예측했는가"가 요구되고, 이 논문이 SHAP dependence plot으로 구간별 임계값(HOMO ≤ −11, HAccN ≥ 1, LUMO < 0, TPSA 10–60) 까지 제시한 건 좋은 벤치마크다. 우리는 여기에 AD + 신뢰도 점수를 얹는다.

④ 화장품 데이터 적용 (Transfer Learning / Domain Adaptation) — 가장 중요한 시사점

이 논문이 우리에게 주는 가장 큰 선물은 "22차원 물리화학 descriptor"라는 저차원 표현이다.

  1. 저차원 = transfer learning에 유리. ECFP 2048비트 fingerprint와 달리 22차원은 화장품 데이터가 수백 건 수준이어도 fine-tuning/재보정이 가능하다. → source(농약 제형, n 큼)에서 학습한 XGB를 화장품에 옮길 때 feature space가 동일하게 정의된다는 점이 domain adaptation의 전제 조건을 만들어 준다.
  2. 혼합물로의 확장이 fingerprint보다 자연스럽다. 물리화학 descriptor는 성분별 가중평균(mole/weight fraction 가중) 이 물리적으로 해석 가능하다. TPSA, LogS, Dipole, Polariz는 가중평균, HOMO/LUMO는 최소/최대값(가장 반응성 높은 성분), HAccN은 합 — 이런 mixture aggregation rule을 정의하면 제형 단위 예측이 가능해진다. (fingerprint로는 이런 물리적 aggregation이 불가능 — 이게 우리 접근의 논리적 근거가 된다.)
  3. 희석/농도 축을 명시적 feature로 추가. 이 논문은 희석액을 배제했지만, 화장품은 본질적으로 희석계다. 농도(%), pH, 제형 타입(수상/유상/에멀전)을 descriptor에 덧붙이는 것이 이 논문 대비 명확한 확장이다.
  4. Domain shift 진단에 이 논문 방법을 재사용. 저자는 train/test 동질성을 Mann–Whitney로 검정했다. 우리는 같은 검정을 source(농약) vs target(화장품) 사이에 돌려서 어떤 descriptor가 도메인 간 분포가 다른지를 정량화하고, 그 결과로 importance weighting / CORAL / feature 재보정 대상을 고른다. 그림 하나로 "왜 transfer learning이 필요한가"를 보여줄 수 있다.
  5. AD가 곧 transfer 여부의 판단 근거. 화장품 성분이 source 모델의 AD 안에 있으면 direct prediction, 밖이면 fine-tuning 필요 — 이렇게 의사결정 규칙을 세운다.

⑤ 화장품 제형의 피부·안 자극성 예측

  • 최종 산출물은 이 논문처럼 "GHS 카테고리 + SHAP 근거 + AD 판정" 3종 세트로 낸다.
  • 규제 문맥에서의 위치 잡기: 저자는 McNamee/Macfarlane의 tiered testing strategy(IATA) 를 인용해 "1단계 물성·QSAR 스크리닝 → 2단계 in vitro 부식성 → 3단계 in vitro 자극성" 구조에서 자기 모델을 1단계에 배치했다. 우리도 IATA 1단계 prescreening tool로 포지셔닝하는 게 가장 설득력 있다 (in vitro를 대체한다고 주장하지 말 것).
  • 화장품은 위음성(자극성인데 비자극으로 예측)이 치명적이므로, 이 논문처럼 Se 우선 운영점을 잡되, Sp를 0.70 이상으로 끌어올리는 것을 목표 성능으로 명시한다.

6. 우리 논문에 인용할 만한 문장/수치

  • 기존 상용 QSAR의 한계: Derek Nexus ACC 0.51 / Se 0.14, Case Ultra ACC 0.59 / Se 0.32 (Verheyen et al., Toxicol Lett 2017) — "기존 in silico 도구는 민감도가 치명적으로 낮다" 는 우리 연구의 동기 문장으로 그대로 사용 가능.
  • OECD TG 431/439 자체 성능 (ACC 0.75~0.79, Se 0.80~0.85, Sp 0.70) — 모델 성능의 합격선.
  • TG 431은 조직모델에 따라 ACC 0.6458~0.7875로 편차가 큼 (80종 reference chemical 기준) → "in vitro도 완벽하지 않다" 는 근거.
  • 현행 OECD TG는 GHS Cat 3(경미 자극) 분류가 불가능 → in silico가 채워야 할 공백.
  • 단일 in vitro 시험으로는 전체 GHS 카테고리를 못 다루므로 2개 이상 조합이 필요 → IATA·통합접근 필요성의 표준 인용.

8. 결론 — 이 논문에서 "가져갈 것"과 "넘어설 것"

가져갈 것 (그대로 채택)

  1. 데이터 큐레이션 4단계 + 신뢰도 점수 필터
  2. Pearson |r| ≥ 0.9 기반 다중공선성 제거 (34 → 22)
  3. 물리화학 + 양자화학(AM1 HOMO/LUMO) descriptor 조합 — fingerprint 없이도 충분하다는 증거
  4. 문제 3분해(ternary + 2 binary) 및 ternary→2×2 접기 비교
  5. 7종 알고리즘 벤치마크 + SHAP 해석
  6. TG 431/439 성능을 합격선으로 삼는 평가 프레이밍
