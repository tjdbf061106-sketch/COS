# 안자극 연구 공유본 · 2026-11-02

저장소 루트의 새 폴더 `eye_research_20261102/`에만 자료를 추가합니다. 기존 파일은 모두 유지하고, 로컬에서 진행한 안자극 데이터 정비·699건 기준선·693건 제외 민감도 분석을 검토할 수 있도록 추가한 자료입니다. 앱, 개발 제안서, Sites 설정, 개인 PC 환경, 논문 PDF는 포함하지 않았습니다.

이 자료는 **안자극 단독 연구 참고 결과**입니다. 현재 저장소의 혼합물 중심 PyTorch 실험을 대체하거나, 두 결과의 성능 우열을 입증하는 자료가 아닙니다. 화장품 전이학습·독립 외부검증은 수행하지 않았습니다.

[skin 팀 자료 확인 내용](skin_review.md)을 함께 참고하세요. 이 폴더를 추가하는 커밋은 기존 README·진행 기록·데이터·코드·모델을 수정하지 않습니다.

## 연구 결과의 범위

- 학습 기준선 699건 = FIFRA 혼합물 606건 + ICCVAM 2006 순물질 93건. 철회 출처 95건은 제외했습니다.
- 693건은 실제 이분류 충돌 3그룹 6건을 학습에서 제외한 민감도 분석입니다. 4등급만 다르고 이분류는 같은 14건은 복원했습니다.
- 주 비교는 두 학습 정책 모두 **동일한 보류 699건**에 대해 수행합니다. 공통 693건 비교는 보조 분석입니다.
- 고정 임계값 0.5에서 AUC는 0.791031(699 학습)과 0.792032(693 학습)입니다. 차이는 0.001001, 기존 짝지은 그룹 부트스트랩 95% 구간은 [-0.006236, 0.008954]입니다. 개선·동등성·비열등성 입증으로 해석하지 않습니다.
- 입력은 공개된 일부 성분의 관측값이며 완전한 화장품 분자 조성이 아닙니다. CTFA의 원료 투입량 완비도와 분자 조성·독립성 확인은 별개입니다.
- 원래 검산 32항목 결과는 `checks/original_verification.json`입니다. 새 공유본 검산은 `checks/share_verification.json`에 별도로 기록합니다.
- 분석계획은 기존 결과를 본 뒤 오류를 수정하고 새 적합 전에 고정한 계획이며, 전향적 사전등록은 아닙니다.

## 실행

이 디렉터리에서 별도 가상환경을 만든 뒤 고정 환경을 설치합니다. 기존 피부 환경과 섞을 필요는 없습니다.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -B reproduce.py
.\.venv\Scripts\python.exe -B reproduce.py --refit-fold 0
```

첫 명령은 파일 해시, 코호트, 라벨, 그룹 분할, 카드, 저장 OOF 지표를 검산합니다. `--refit-fold 0`은 기준선/제외 정책 각각의 첫 외부 폴드를 원본 전처리·RF·난수로 재적합해 저장 예측과 대조합니다. 내부 임계값 재탐색이나 전체 연구 재실행, 화장품 예측을 수행하는 명령은 아닙니다. 저장된 신뢰구간의 전체 재표집도 이 명령의 검산 범위에 포함되지 않습니다.

## 피부 팀과 맞출 사항

1. **공통 원칙**: 조성 그룹 분리, 전처리의 학습 폴드 내부 적합, 고정 임계값과 조정 임계값의 구분, 표본 수·양성 수·평가 단위 명시.
2. **별도 정의**: 피부/눈의 결과와 시험조건은 각각 유지합니다. EPA III·IV를 일괄적으로 “자극 없음”으로 설명하지 않습니다.
3. **입력 차이**: 피부의 541건·2,266특성(nz20 이전)과 이 자료의 699건·2,280특성은 같은 분석 모집단·입력 정의가 아닙니다. AUC 숫자를 직접 경쟁시키지 않습니다.
4. **코드 현황**: 현재 팀 저장소에는 멀티태스크 harness가 남아 있습니다. 사용자가 제시한 피부·눈 독립 모델 개발 방향과의 조정은 별도 결정 사항이며, 이번 공유에서 팀 코드를 수정하지 않았습니다.

## 출처와 이용

- NTP ICE에서 확보한 공개 시험자료를 COS가 정리한 파생 데이터입니다. 기존 팀 원자료는 `../eye irritation/eye_irritation.xlsx`이며, 본 공유의 실제 입력은 별도 정비·제외 정책을 적용한 `data/eye_retained699.csv`입니다.
- 원료·제형 자료의 원 논문 위치와 페이지는 `formulation_reference/`의 `source_url`, `recipe_url`, `label_url` 열에 보존했습니다. 공급원료의 참고 CAS/SMILES는 전체 혼합물 조성을 의미하지 않습니다.
- [NTP 자료 이용 정책](https://ntp.niehs.nih.gov/support/policies): 별도 저작권 표시가 있는 자료는 해당 조건을 따릅니다. 이 공유가 제3자 원문에 새 라이선스를 부여하지 않습니다.
- `training_lock.json`과 `source_snapshot/`에는 원래 연구 폴더 기준 상대경로가 남아 있습니다. 공유본 파일 검산에는 `manifest.json`을 사용합니다.
