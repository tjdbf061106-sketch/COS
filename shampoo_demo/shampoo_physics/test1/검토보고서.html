판단: 원료 정보를 기록하고, 실측 자료를 추가한 뒤 제한된 범위에서 예측을 지원하는 절차는 구현 가능합니다. 다만 현재 문서는 연구 설계 초안입니다. 신규 원료의 실제 편입 성공, 최소 실험 수, 예측 성능을 아직 입증한 것은 아닙니다. 실험을 할 수 없다면 학술제의 핵심은 공개 실측 자료의 비교 연구와 적용범위 관리로 정하는 것이 현실적입니다.

이미 812개 제형, 세 물성 모델, 그룹 평가 예측, 44개 실측 출발 처방이 있어 결과물이 없는 상태는 아닙니다. 남은 핵심은 성능의 한계를 숨기지 않고, 사전에 정한 비교 질문에 답하는 것입니다. 높은 성능이나 학술제 평가 결과를 보장할 수는 없습니다.

4. 앱에서 재현한 구체적인 문제

사례 A — 이름을 NEW_SUPPLIER_UNVERIFIED로 주고 Plantacare 2000의 대표 SMILES를 함께 넣으면 resolve_ingredient가 기존 Plantacare 2000에 status=resolved로 연결합니다. 메시지는 등급 확인 필요라고 알리지만 app.py의 차단 조건은 resolved 여부이므로 이 미확인 상태만으로는 차단되지 않습니다. 공급사 동일성이 확인됐다는 증거는 없습니다.

사례 B — 관측이 한 번뿐인 제형 ID 38에서 Texapon SB 3 KC를 12.24%에서 전체 데이터의 상한인 16.24%로 바꿔도 applicability는 interpolation을 반환합니다. 같은 조합의 관측점이 한 개이므로 이 변경점은 그 조합에서 관측한 점들의 볼록껍질 안에 있지 않습니다. 실제 안정성·오차는 측정되지 않았으며 이 사례로 나쁜 물성이 생긴다고 주장하는 것은 아닙니다.

사례 C — 저장된 주평가는 정확히 같은 원료 조합을 학습과 평가 사이에서 분리합니다. 학습에서 본 조합만 승인하는 규칙을 각 학습 fold 안에서 적용하면 평가 15개 fold 모두 승인 비율은 0%입니다. 현재 앱이 실제로 100% 거부한다는 뜻은 아닙니다. 현재 앱은 범위 밖에도 수치를 표시합니다. 이 결과는 향후 보류 규칙을 도입할 때 평가 분할과 실제 지원 범위의 정의를 함께 맞춰야 한다는 뜻입니다.

개선: 알려진 원료의 새로운 조합 예측, 같은 조합에서 농도 변경, 완전히 새 원료 편입을 서로 다른 평가 문제로 정의합니다. 적용범위 필터·거리·스케일링·임계값은 각 학습 fold만으로 만들고, 평가 fold의 정답으로 조절하지 않습니다. 그룹 평가와 전처리 분리 원칙은 scikit-learn 공식 문서에도 설명돼 있습니다. [2]

5. 수정 프로토콜 제안

순서완료 조건
1. 목표와 지원 단위 고정신규 원료/공급사/등급 중 무엇이 바뀌는지, 단기 안정성 또는 특정 전단속도의 물성 중 무엇을 지원할지 명시
2. 정보·비교 처방 등록원료 규격·활성분의 기준·물/염/고형분·등급·로트·문서 버전을 기록하고 미확인 값을 남김
3. 실험·분할 사전 고정대조 처방, 제약된 농도 조합, 독립 제조 반복, 시험 순서를 설계. A 개발용과 B 잠금 평가용을 그룹 단위로 구분
4. 측정과 QC제조 순서·혼합 에너지·실측 pH·적정액·온도·관찰시간·기기와 전단속도·단위·원시 반복값을 보존. 안정성부터 판단하고 결측 사유를 기록
5. 개발용 자료로 모델 갱신기존 자료+A로 입력 스키마를 확장하고 재학습. 전처리·임계값·선택은 개발 자료 내부에서 결정. 기존 원료 성능 저하도 확인
6. 잠금 평가와 제한 등록한 번 잠근 B로 네 분류 지표·회귀 오차·지원 비율을 평가. 부족하거나 기준 미달이면 보류. B로 다시 조정했으면 더 이상 최종 평가라고 부르지 않음

B가 별도 조합의 내부 보류셋인지, 다른 제조 배치·시험 시점에서 얻은 전향적 검증인지 구분합니다. 제품·시험 식별자로 독립성이 확인되지 않은 자료는 확증적 독립 외부검증으로 부르지 않습니다. 최소 실험 수는 혼합물 제약, 필요한 모델 복잡도, 배치 변동과 원하는 오차 정밀도에 따라 정하며, 몇 개만 측정하면 충분하다고 고정하지 않습니다. [3]

분류에서는 안정·불안정 표본이 모두 필요합니다. 한 클래스만 있으면 일부 지표를 계산할 수 없으며 0 또는 1을 임의로 넣지 않습니다. 실측 안정 처방에서의 물성 오차와, 전체 후보 중 실제 불안정한 처방을 통과시키는 오류를 따로 보고합니다. 좋은 안정성 분류만으로 점도·탁도 지원까지 일괄 승인하지 않습니다.

6. 학술제에서 현실적인 핵심 결과

권장 연구 질문: ‘제형의 입력 표현과 원료 정보의 불확실성이 샴푸 물성 예측의 균형과 적용범위 판단에 어떤 영향을 주는가?’ 현재 자료로 답할 수 있는 질문이며 개선이 없거나 특정 조건에서 실패하는 결과도 남길 수 있습니다. 예쁜 앱이나 프로토콜 도식만으로 연구 결과를 대신하지는 않습니다.

후속신규 원료 모의 편입공개 자료의 원료 하나를 가린 뒤 같은 원료의 일부 조합을 개발용으로 추가하고 나머지를 고정 평가. 실제 새 원료 검증과 구분

비교 모델을 고르거나 임계값을 튜닝한다면 내부 그룹 검증에서만 선택하고 외부 fold는 평가에 사용합니다. 이미 본 OOF에 맞춰 설정을 반복 선택하면 선택 편향이 생깁니다. 같은 자료로 수행한 추가 비교는 재사용한 내부 평가임을 명시해야 합니다.

모의 편입은 전체 원료 목록과 포함 조건, 분할, 추가 자료 예산을 예측 전에 고정하고 원료별 결과를 모두 보고합니다. 유리한 원료 하나만 결과를 본 뒤 고르지 않습니다. 같은 처방이 여러 원료의 평가에 중복될 수 있으므로 원료별 결과를 서로 독립인 18개 실험처럼 합치지 않습니다. 이미 전체 자료로 학습된 저장 모델을 그대로 가져와 ‘가린 원료를 보지 않았다’고 주장하지 않고, 각 실험에서 처음부터 학습합니다.

실제 제조·측정이 가능하면 위 비교 연구 뒤에 신규 원료 1종의 제한된 편입 사례를 추가할 수 있습니다. 실험이 어렵다면 신규 원료 부분은 모의 편입 결과 또는 후속 프로토콜로 제시합니다. 어느 경우에도 ‘어떤 새 원료든 예측하는 완성 모델’이나 ‘최소 실험으로 편입 성공’을 현재 성과로 쓰지 않습니다.

7. 저장된 근거와 검토 범위

검토 결과는 test1 안에만 저장했습니다. 원본 Word 문서, 기존 앱·모델·데이터, GitHub는 수정하지 않았습니다. 이번에는 실행 계획과 현재 동작을 감사했으며 보강 입력 재학습이나 신규 원료 실험은 수행하지 않았습니다. 소스 파일의 검토 전후 해시가 같습니다.
