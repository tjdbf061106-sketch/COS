## 현재 결과를 읽을 때

- 상안정성은 원자료 조건에서의 단기 관찰입니다. 장기 안정성이나 제품 사용성을 보장하지 않습니다.
- 기존 18개 원료를 대상으로 한 신규 원료 편입은 **후향적 모의 실험**입니다. 실제 신규 원료의 독립 검증은 아닙니다.
- 피부·눈 구조 자료는 참고 자료로만 관리합니다. 피부·눈 라벨을 샴푸 물성 학습에 넣거나 완제품 자극성을 예측한 결과가 아닙니다.
- 모델 출력이나 후보 제형은 추가 실험과 검토를 위한 참고자료이며, 자동 처방 확정이나 안전성 판정이 아닙니다.

## 실행

기준선 앱은 이 폴더에서 실행합니다.

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

개정 앱은 `test1/revision_v1/`에서 해당 폴더의 `requirements.txt`를 설치한 후 `python -m streamlit run app.py`로 실행합니다. 개정 앱은 이 프로젝트의 `../../models/`와 `../../results/`도 읽으므로 폴더 구조를 유지해야 합니다. 학습된 `joblib` 파일은 신뢰할 수 있는 출처인지 확인한 뒤 로드해야 합니다.

저장된 기준선 결과를 이 저장소의 중첩 경로에서 검사할 때는 전체 COS 저장소를 내려받은 뒤, 이 폴더에서 `python src/verify_shared_baseline.py`를 실행합니다. 이 공유용 검증기는 원래 피부·눈 입력의 해시도 확인하고 기존 결과 파일을 덮어쓰지 않습니다. 원본 README의 `src/verify.py`와 데이터 재생성 스크립트는 원래 프로젝트가 저장소 최상위에 있다는 경로 가정을 사용하므로, 이 중첩 폴더에서 그대로 실행하면 경로 오류가 날 수 있습니다.

## 공유용 경로 수정과 재현

공개 공유를 위해 개인 PC 절대경로 4곳을 상대경로·환경변수 또는 일반 실행 명령으로 바꾸고 관련 배포 목록 해시를 갱신했습니다. 변경 전후 해시는 [share_amendment.json](share_amendment.json)에 기록했습니다. 기준선 학습 잠금과 개정 연구의 분석 잠금, 측정 결과와 모델은 변경하지 않았습니다. Git의 줄바꿈 변환이 잠금 해시를 바꾸지 않도록 이 폴더의 파일 바이트를 보존합니다.

`test1/audit_feasibility.py`를 다시 실행하려면 별도 보관된 원본 프로토콜 DOCX를 `test1/original_protocol.docx`에 두거나 `SHAMPOO_PROTOCOL_DOCX` 환경변수로 위치를 지정해야 합니다. 원본 사용자 문서는 이 공유본에 포함하지 않았습니다. 실행 시 기존 산출물을 다시 쓸 수 있으므로 재실행은 별도 복사본에서 하세요.

저장된 결과와 과거 검증 기록은 당시 환경의 기록입니다. 다른 컴퓨터에서 동일한 결과를 주장하려면 명시된 의존성과 입력 파일, 잠금 해시를 확인하고 별도로 재실행해야 합니다.
