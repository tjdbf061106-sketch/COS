# Shampoo Demo — B안 샴푸 물성 설계 연구

> **공유 자료 보충:** 로컬 `shampoo_physics`의 앱, 분석 결과, 신규 원료 편입 검토 및 개정본을 [shampoo_physics/](shampoo_physics/)에 추가했습니다. 기존 [`research_package_20261102/`](research_package_20261102/)는 그대로 보존합니다. 아래의 기존 계획·상태 표는 초기 계획이며, 후속 작업의 실제 범위와 실행 안내는 [보충 자료 안내](shampoo_physics/GITHUB_SHARE_GUIDE.md)와 각 폴더의 README를 확인하세요.

> **팀 검토용 새 프로토콜:** [Word 문서](docs/new_ingredient_improvement_protocol.docx) · [PDF](docs/new_ingredient_improvement_protocol.pdf) — 신규 원료 정보, 실험·평가 분리, 기준 미설정 시 보류와 역할 분담을 정리한 초안입니다.

## 한 줄 목적

공개 실측 샴푸 제형을 이용해 **단기 상안정성**을 먼저 검토하고, 실제로 안정한 제형 범위 안에서만 목표 탁도·점도에 가까운 실험 후보를 찾는 연구·데모입니다.

이는 피부·안자극성 전이학습이나 안전성 판정 도구가 아닙니다. skin·eye 모델의 데이터·라벨·checkpoint는 물성 모델 학습에 넣지 않습니다.

## 데이터와 범위

- 원자료: Chitre et al. (2024)의 공개 액체 제형 데이터
- 제형 수: 812개
- 원료: 18개 상용 원료
- 관측값: 제형 조성, 단기 상안정성, 탁도, 유변/점도–전단률
- 물성 회귀 표본: 실제로 안정하고 해당 물성 측정값이 존재하는 제형만 사용

상안정성은 pH 5.8 ± 0.2 조정 전후, 최종 36시간 관찰이라는 원 연구 조건의 단기 결과입니다. 장기 보관 안정성, 유통기한, 실제 사용감, 모든 상용 샴푸에 대한 일반화를 뜻하지 않습니다.

원료는 상용 혼합물입니다. 대표 SMILES나 INCI 표기는 실제 원료 분포 전체를 완전하게 표현하지 않으므로, 구조 정보는 참고·적용범위 점검용으로만 사용합니다.

## B안 모델링 파이프라인

```text
0. 원자료 동결
   공개 원본 + 원료 정보 + 구조 참고 자료 + SHA-256 기록
   ↓
1. 데이터 감사
   제형 ID / 단위 / 원료 투입량 / 활성분 / 결측 / 반복 측정 / 전단률 구조 점검
   ↓
2. 평가 계획 고정
   동일·근접 조성 및 반복 측정을 같은 group으로 묶어 hold-out
   전처리·feature 선택·threshold는 학습 fold 안에서만 적합
   ↓
3. 상안정성 분류
   조성 → 안정 / 불안정
   Logistic Regression, 트리 기반 기준선을 같은 group split에서 비교
   ↓
4. 조건부 물성 회귀
   안정 + 실제 측정값 존재 제형만 사용
   조성 → 탁도, 조성 → 고정 전단률의 점도
   ↓
5. 후보 탐색
   (a) 실측 안정 제형 중 목표와 가까운 출발 후보 제시
   (b) 검증된 적용범위 내부에서만 새 후보를 연구용으로 탐색
   ↓
6. 앱 연결
   예측값, 실측값, 미확인 정보, 적용범위 경고를 분리 표시
```

## 성능·의사결정 원칙

### 상안정성 분류

Sensitivity, Specificity, MCC, ROC-AUC를 함께 보고합니다. 어느 하나가 높다는 이유만으로 모델이 좋다고 결론 내리지 않습니다.

- Sensitivity: 실제 불안정 제형을 안정이라고 잘못 통과시키지 않는가
- Specificity: 실제 안정 제형을 불필요하게 탈락시키지 않는가
- MCC: 클래스 비율을 고려한 전체 판정의 질이 우연보다 나은가
- ROC-AUC: threshold와 독립적으로 안정/불안정을 얼마나 잘 순위화하는가

Sens–Spec 격차는 보조 지표입니다. 격차가 작더라도 두 값이 모두 낮으면 좋은 모델이 아닙니다. threshold는 결과를 본 뒤 전체 데이터에서 맞추지 않고, 학습/검증 범위 안에서 고정하거나 선택 근거를 남깁니다.

### 탁도·점도 회귀

회귀에는 Sensitivity·Specificity를 사용하지 않습니다. 로그 척도 MAE, R², 잔차 패턴, 목표 범위 적중률 및 오차대를 함께 봅니다. 불안정 제형의 미측정 물성은 0이나 임의 추정값으로 채우지 않습니다.

## 앱 구성

앱은 **물성 탐색 화면**과 **근거 추적 화면**을 분리합니다. 모델이 아직 검증되지 않은 범위에서는 예측을 감추고, 데이터 부족·적용범위 밖·실험 필요성을 먼저 표시합니다.

### 1. 샴푸 물성 탐색 화면

입력:

- 18개 원료별 투입량
- 목표 탁도
- 목표 점도와 고정 전단률
- 선택 사항: 제품명, 실험 메모

입력 검증:

- 투입량 합계와 단위
- 학습 원료 외 원료 존재 여부
- 각 원료 농도의 학습 범위 이탈 여부
- 상용 원료 활성분/등급 미확인 여부

출력:

- 단기 상안정성: 확률, 판정 threshold, Sens/Spec/MCC/ROC-AUC가 함께 있는 모델 카드
- 탁도·점도: 예측값, 사용한 전단률, 검증 MAE·오차대
- 실측 출발 제형: 목표와 가까운 실제 측정 제형 목록
- 경고: 적용범위 밖, 물성 미검증, 새 후보는 후속 실험 대상이라는 문구

### 2. 처방 변경 근거 추적 화면 (A안과 연결)

입력한 기준 처방과 변경 처방을 비교해 원료·투입량·공급사·원료 등급·활성분·시험 조건의 차이와 미확인 정보를 보여줍니다. 이 화면은 자극성·안전성 점수나 시험 면제를 판정하지 않습니다.

## skin 트랙이 해야 할 일

skin은 B안의 학습 데이터나 자극성 라벨을 제공하지 않습니다. 맡을 일은 **검증 원칙과 한계 관리**입니다.

1. 동일·근접 조성 누수가 없는 group-aware 평가 규칙을 B안 코드에 적용합니다.
2. feature 선택, 표준화, threshold 선택이 평가 fold 밖 정보를 보지 않도록 코드 리뷰합니다.
3. 물성 후보를 피부자극성 안전성으로 오해하지 않게 앱·보고서의 경고 문구와 적용범위 설명을 검토합니다.
4. 동일 샴푸 제형의 피부자극 실측 라벨이 없는 한, skin 모델을 B안 후보 점수·필터·라벨로 사용하지 않습니다.

## eye 트랙이 해야 할 일

eye도 B안의 물성 학습 라벨을 제공하지 않습니다. 맡을 일은 **시험 근거와 처방 변경 정보의 연결**입니다.

1. A안 근거 추적기에 사용할 CTFA 제형·시험농도·제품군 참고 자료를 출처 단위로 정리합니다.
2. 원료 공급사·등급·활성분·시험농도 변화가 있을 때 어떤 기존 안자극 시험 근거가 비교 불가능해지는지 체크리스트를 검토합니다.
3. 샴푸 물성 결과를 안자극 예측 또는 외부검증으로 표현하지 않도록 보고서·앱 문구를 검토합니다.
4. 같은 샴푸 제형의 신뢰할 수 있는 안자극 라벨과 입력 호환성이 확보되기 전에는 eye 모델을 B안 후보 평가에 사용하지 않습니다.
