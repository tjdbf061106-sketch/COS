외부검증 결과 안내

외부검증 공개 결과 패키지

범위: 로컬 「외부 검증」 폴더의 보고서와 핵심 근거 결과를 GitHub 「최종/외부검증」에 선별 공개한 패키지입니다. 모델 전체·학습 입력·실행 환경을 포함하는 재현 패키지가 아닙니다.

핵심 결론
농약 제형 기반 자극성 모델의 화장품 관련 자료 적용 가능성을 탐색했습니다. 화장품 피부·안자극 성능 또는 안전성을 확정한 결과가 아닙니다. Eye와 Skin 결과는 분리해서 읽어야 합니다.
Zein은 EPA 눈자극/피부자극 정답이 아닙니다. Zein 기준 일치율·AUC·새 Zein head의 결과를 EPA 성능이나 안자극 개선으로 표현하지 마세요.
원시험 EPA 정답, 평가 제형과의 연결, 학습 원시험 독립성을 함께 확보한 외부검증 표본은 현재 확인 목록에서 0건입니다.

읽는 순서
1. EPA_재검토_추가자료_20261109/정정_및_추가자료.txt: 최초 샴푸·CIR 결과 해석보다 정정을 우선합니다.
2. Eye_재외부검증_20261109: 특허 혼합물 및 추가 샴푸에 대한 탐색 비교.
3. Lechuga2025_화장품_외부검증_20261109: 대표구조 가정 포함 분석과 적용범위 재분석.
4. Lechuga_Eye_A_B_엄격검토_20261109: 대표구조를 임의 생성하지 않은 별도 명칭 구조 기준 분석. 모든 성분명이 해결됐다는 것이 상업 시험시료 전체 조성/순도까지 확인됐다는 뜻은 아닙니다.
5. Skin_Lechuga_외부검증_20261109: Skin 모델의 별도 Zein 비교 노트북과 입력 결과표. Eye 결과와 합산하지 않습니다.
6. UVCB_민감도_비교_20261109: 구조 가정에 따른 민감도 보조 결과.
7. Eye_Lechuga_전이탐색_20261109: Zein 관련 별도 탐색 실험입니다. 안자극 학습 성공이나 화장품 안자극 검증으로 해석하지 않습니다. 이 폴더의 계보 설명은 그 실험 범위에 한정됩니다.
8. 검증데이터_목록_20261109 및 샴푸6제품_원시험추적_20261109: 근거·미확인 사항·원시험 추적 상태.

해석 주의
적용범위 부분집합에서 역상관이 뚜렷하지 않다는 사실은 외삽이 원인임을 입증하거나 내부 성능이 우수함을 입증하지 않습니다. 작은 표본과 넓은 신뢰구간을 함께 고려해야 합니다.
일부 원보고서는 재현 명령·원본 폴더 파일명을 언급하지만 해당 실행 스크립트는 이 결과 공개 묶음에 포함하지 않았습니다. 노트북은 함께 둔 github_data를 사용합니다.
서로 다른 선별 기준의 보고서 건수는 합산하지 않습니다. 초기 결과와 정정 이후 해석을 구분합니다.

선별 원칙
포함: 주요 보고서, 핵심 예측 CSV, 구조·적용범위·민감도 결과, EPA 해석 정정, 근거 목록.
제외: 중복 모델/학습 스냅샷, 캐시/로그/환경, 다운로드 발췌 모음, 중복 엑셀, 로컬 경로 의존 생성·실행 스크립트, 미발송 요청문, 별도 외부학습 폴더.
「종합보고서/종합외부검증보고서.html」은 외삽 원인 확정·제도적으로 자료 생성이 중단됐다는 단정 표현이 있어 이번 공개 요약으로 채택하지 않았습니다. 그 단정은 현재 확보 자료만으로 뒷받침되지 않습니다. 로컬 원본은 변경하지 않았습니다.
일부 사용자별 절대경로는 공개본에서 LOCAL_COS로 바꿨습니다. 수치 결과는 바꾸지 않았으며 원본/공개본 SHA-256은 upload_manifest.json에 기록했습니다.
GitHub HTML 파일은 코드로 보일 수 있습니다. 내려받아 브라우저에서 열거나 Raw 파일을 저장해 열어주세요. ipynb는 GitHub에서 열람할 수 있습니다.
