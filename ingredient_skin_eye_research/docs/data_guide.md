# 데이터 안내

공유 파일은 2026-11-03 기준의 작업 사본입니다. 공개자료에서 얻은 결과는 모두 **이미 결과가 확인된 개발자료 후보**이며, 최종 눈가림 평가용 라벨이 아닙니다.

## 후보 및 위험 상태

| 파일 | 설명 |
|---|---|
| `data/candidates/evidence_axes.csv` | 피부 24행·눈 43행. `target_assay_compatibility`, `study_lineage_independence`, `risk_evidence_status`를 분리 |
| `data/candidates/joint_risk_status.csv` | 피부·눈 후보를 물질 단위로 연결한 55행. 공동 검토 후보 0건 |
| `data/candidates/outcome_exposure_log.csv` | 공개자료 검색 중 확인된 결과 노출과 후속 보류 이력 |

한 물질이 피부와 눈 양쪽에 나타나므로 67행을 67개 독립 물질로 세지 않습니다. A/B/C는 모두 `unassigned`, 최종 등록은 모두 거짓입니다.

## 개발자료

| 파일 | 범위 및 주의점 |
|---|---|
| `eye_2014_runs.csv` | EURL ECVAM EpiOcular 검증 프로그램 76개 CAS, 828개 반복 관측. 원문 셀 수치 758개 대조, 70개 결측 또는 수동 확인 필요 |
| `eye_2014_materials.csv` | 위 자료를 물질·프로토콜 단위로 요약한 기술 통계. 액체·고체 원래 조건·고체 최적화 조건 분리 |
| `eye_oecd492_2023.csv` | OECD TG 492 2023년 과거 판본에 실린 개발용 11개 물질. 2025년 판본과 구별 |
| `skin_epiderm_2004_15min_42h.csv` | 과거 EpiDerm 15분 노출·42시간 자료 4물질. 현 목표인 60분 자료가 아님 |
| `skin_vitrolife_2008_18h.csv` | Vitrolife 18시간 자료 13물질 |
| `skin_vitrolife_2008_42h.csv` | Vitrolife 42시간 자료 13물질. 18시간 파일의 물질과 반복될 수 있음 |

`eye_2014_runs.csv`의 828행은 독립 물질·독립 원시험의 수가 아닙니다. 한 검증 프로그램에서 복수 실험실과 반복 실행을 기록한 것입니다. 물질 이름이 복잡하거나 누락된 두 CAS는 추가 검토가 필요합니다. 시험물질의 순도·배치·원시험 동일성도 확인되지 않았습니다. 따라서 그대로 확정 라벨로 학습하거나 성능을 주장해서는 안 됩니다.

추출 시 최종평가 예약 검색 단서 105개에 대해 CAS, 구조·부모구조 및 Morgan 지문 Tanimoto 0.70 이상 유사성을 기준으로 보수적으로 제외했습니다. 이는 원시험·실험실·배치 독립성의 증명이 아닙니다. 기존 학습 193개 물질은 미지 물질 외부검증에 사용할 수 없으며 일부는 개발자료에 포함될 수 있습니다.

## 출처 및 이력

`data/sources/source_register.csv`에는 공개 출처와 접근 여부가 있습니다. 일부 링크와 공개 문서에는 후보 결과가 있을 수 있습니다. `request_history_not_sent.csv`의 요청은 전부 미발송입니다. 원문 PDF는 재배포하지 않습니다.

`data/research_workbook.xlsx`에는 위 항목과 추가 추적표가 포함됩니다. 공유 사본에서 로컬 PC 절대경로를 제거했습니다. 파일의 결과 열을 최종평가 담당자의 눈가림 자료로 사용하지 마세요.
