# 공유와 후속 작업

## GitHub 공유 전

이 폴더는 복사해서 Git 저장소에 넣기 쉽도록 준비한 **로컬 공유본**입니다. 아직 저장소 생성, 커밋 또는 업로드를 수행하지 않았습니다.

1. 저장소 공개 범위를 결정합니다. 후보 CAS, 시험 결과, 연구 진행 상황이 들어 있으므로 팀 협업이라면 먼저 비공개 저장소를 검토합니다.
2. 공개 저장소에 원자료 또는 그 파생 데이터를 게시하기 전 각 출처의 저작권과 재사용 조건을 확인합니다. 공개 열람 가능하다는 사실이 재배포 허가를 뜻하지는 않습니다. 출처별 검토는 아직 완료되지 않았습니다.
3. 개인 연락처, 접근 토큰, 사내 비공개 문서와 불필요한 PC 경로를 추가하지 않습니다. 외부 원문 PDF는 이 공유본에 포함하지 않았습니다.
4. 최종평가 라벨을 보관할 독립 담당자에게 결과가 포함된 개발자료·원문 링크를 무심코 전달하지 않도록 역할과 접근 권한을 분리합니다.

## 결과 노출과 평가 독립성

자료 검색 중 CAS 2365-48-2의 공개 결과가 표시되었습니다. 해당 물질은 피부·눈 양쪽의 향후 전향적 눈가림 최종평가에서 제외했습니다. 공개 참고자료의 눈 Category 1 기록에 따라 위험을 보수적으로 보류했지만, 실제 상용 시험물질의 배치 동일성은 확인되지 않았습니다. 다른 후보의 과거 결과 노출 여부도 확인되지 않았습니다.

확증 평가용 자료는 모델 개발, 후보 선정·포함 기준, 시험법, 구조 및 원시험 중복 검사, 임계값·보류 기준을 정하고 모델·환경·예측 해시를 기록한 다음 독립 관리자가 결과를 공개해야 합니다. 결과를 이미 확인한 공개자료는 이러한 눈가림 최종평가로 다시 부를 수 없습니다.

## 다음 작업

- 피부와 눈에서 원시험 ID·실험실·연도·시험조건·물질 순도 및 배치와 공개표의 연결을 추적합니다.
- 피부는 목표 60분 EpiDerm 자료를 추가 확보하거나 실제 확보 가능한 다른 시험법을 별도 표적으로 정의합니다.
- 눈은 Draize/GHS 원자료 추적과 비동물 시험법별 개발자료 구성을 병렬로 진행합니다. 각 표적을 자동으로 합치지 않습니다.
- 독립 라벨 관리자를 확보하고, 피부와 눈 각각 시험법별 개발자료의 범위·독립 출처·보류 규칙을 확인합니다.
- 파일럿은 확보율·자료 분포 등 기술적 타당성만 점검합니다. 확증 표본수, 신뢰구간과 모델 차이의 검정력은 미래 평가 라벨을 보기 전 별도로 정합니다.

사전 계획에 적힌 과거 표본수는 정식 비교 검정력 계산 결과가 아닙니다. 결과를 확인한 뒤 기준을 낮추지 않습니다.
