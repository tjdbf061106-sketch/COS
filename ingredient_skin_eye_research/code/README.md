# 위험 게이트 v2.1

`risk_gates.py`는 연구의 입력 형식과 위험 근거에 따른 보류 규칙을 담습니다. `gate`는 위험 근거 `positive`, `negative`, `unknown`, `conflict`와 실제 불리언인 품질 확인값을 받습니다. 양성이면 보류하고, 충돌·미확인 또는 확인되지 않은 음성도 통과시키지 않습니다. 확인된 음성만 위험 게이트를 통과하며, 이는 안전 판정이 아닙니다.

`joint`는 피부·눈 위험 게이트 상태와 각 근거 및 모델 통과 여부를 검사합니다. 네 확인값은 반드시 Python `bool`이어야 하며 문자열 `"False"`, 숫자, 빈 값과 `None`은 거부합니다. 두 축이 모두 조건을 충족해도 결과의 의미는 공동 검토 후보이며 안전성 승인과 다릅니다.

이 버전은 기존 v1에서 문자열이 참값으로 해석될 수 있던 문제를 수정하기 위해 v2를 공식화하고 공동 판정 입력의 형 검사를 보강한 것입니다. 현재 복사한 파일의 내용은 2026-11-03 연구 작업본의 정식 v2.1과 동일합니다. 위험 근거 자체의 신뢰성은 입력값과 별도로 평가해야 합니다.

```bash
python -m unittest discover -s code -p "test_*.py" -v
```

테스트는 형 안전성과 보수적 분기 동작을 점검합니다. 생물학적 정확도나 모델 예측 성능을 검증하지 않습니다. 전체 데이터 추출 파이프라인은 별도의 원본 자료와 PC별 경로에 의존하므로 이 공유본에 재현 가능한 형태로 포함되어 있지 않습니다.
